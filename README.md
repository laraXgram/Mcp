## Introduction

LaraGram MCP allows you to rapidly build MCP servers for your LaraGram applications. MCP servers allow AI clients to interact with your LaraGram application through the [Model Context Protocol](https://modelcontextprotocol.io/docs/getting-started/intro).

## Official Documentation

Documentation for LaraGram MCP can be found on the [LaraGram website](https://laraxgram.github.io/v4/mcp).
